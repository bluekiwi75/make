# 마켓데스크 Claude 인계

이 ZIP은 2026-11-21 한국시간 기준으로 저장한 마켓데스크 소스와 실행 도구입니다.

## Claude에서 확인하기

1. ZIP을 Claude 또는 Claude Code의 작업 폴더에 풀어 주세요.
2. Node.js 22 이상이 설치된 터미널에서 `node run-local.mjs`를 실행하세요.
3. 브라우저에서 `http://127.0.0.1:8787/`을 열면 샘플 데이터로 주문, 상품, 원가, 사입 화면을 확인할 수 있습니다. 환경에서 포트 전달을 지원한다면 8787 포트를 사용하세요.

실행 도구는 먼저 빌드하고 루프백에서 웹 서버를 엽니다. 패키지 관리자를 설치할 필요가 없습니다. 샘플 데이터의 수정은 브라우저 새로고침 전까지 유지됩니다. 사입 서류 읽기 기능은 PDF 및 문자 인식 라이브러리를 불러올 때 인터넷 연결이 필요합니다.

## 소스와 운영 데이터

- 프런트엔드: `public/`
- 저장, 주문 연동 및 원본 보관 Worker: `worker.mjs`, `markets.mjs`, `additional-markets.mjs`
- 빌드: `node build.mjs` 후 `dist/server/index.js`
- 데이터 구조: `drizzle/`
- 운영 사이트: https://market-desk-261118.bluekiwi75.chatgpt.site/

운영 주문, 원가, 재고, 사입 기록은 기존 마켓데스크의 클라우드 D1에 남아 있고, 새 사입 원본은 R2에 저장됩니다. 이 ZIP에는 운영 데이터, 사입 원본, 비밀번호 또는 API 키가 없습니다. 실제 자료로 작업하려면 기존 운영 사이트에 같은 계정으로 접속하세요.

별도 배포에는 D1 DB, R2 BUCKET, 사용자 인증, 판매처 연동 비밀값을 별도로 구성해야 합니다. 원본의 Sites 식별자는 기존 운영 사이트를 설명하기 위해 포함했습니다. 독립 사이트를 만들 때는 새 환경의 식별자를 사용하세요.
