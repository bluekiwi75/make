# 삭제한 기능 보관함

사용자가 삭제하라고 한 기능은 **지우기 전에 되살릴 수 있는 기준을 남깁니다.** 아래 표에서 언제 무엇을 지웠는지, 어느 커밋으로 되돌리거나 합칠 수 있는지 찾습니다.

## 복원 방법
- 코드: `git show <복원 기준 커밋>:public/app.js` 로 그때의 파일을 볼 수 있습니다. 일부만 되살릴 때는 필요한 함수만 현재 파일에 옮기고, 전체를 되돌릴 때는 `git checkout <복원 기준 커밋> -- public/app.js public/app.css` 후 현재 변경을 다시 합칩니다.
- 데이터: 아래 ‘보관한 값’을 앱 화면(또는 `ArtifactData`)으로 다시 입력합니다.
- 기능을 다른 기능과 합칠 때도 같은 커밋의 코드를 참고합니다.

## 새로 삭제할 때 남기는 것
1. 지우기 **전에** 현재 상태를 커밋·푸시해 복원 기준 커밋을 만듭니다.
2. 이 표에 줄을 추가합니다(작업 번호, 지운 것, 복원 기준 커밋, 보관한 값).
3. 데이터를 지울 때는 값(이름·수치)을 ‘보관한 값’에 적고, 개인 정보나 비밀번호는 적지 않습니다.
